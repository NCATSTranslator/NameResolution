# NameRes v1.5.2 Release
- Babel: [2025sep1](https://stars.renci.org/var/babel_outputs/2025sep1/)
  ([Babel 2025sep1](https://github.com/NCATSTranslator/Babel/blob/main/releases/2025sep1.md))
- NameRes: [v1.5.2](https://github.com/NCATSTranslator/NameResolution/releases/tag/v1.5.2)

Next release: _None as yet_
Previous release: [NameRes v1.5.1](./v1.5.1.md)

This release is functionally identical to [NameRes v1.5.1](./v1.5.1.md) apart from the metrics support
described below, so everything in the v1.5.1 release notes applies here as well.

It is the most recent NameRes release that can load Babel exports without the `taxon_specific` flag, which
[NameRes v1.6.0](https://github.com/NCATSTranslator/NameResolution/releases/tag/v1.6.0) began to require.
It therefore supports Babel releases up to and including
[2025sep1](https://github.com/NCATSTranslator/Babel/tree/main/releases/2025sep1). The metrics code added
here was never directly ported to the 1.6.0 or subsequent releases -- instead, it was reimplemented there.

## New Features
- Added Solr and query metrics ([PR #253](https://github.com/NCATSTranslator/NameResolution/pull/253)).
  - `/status?full=true` reports more detailed Solr information, including memory/CPU and cache information.
  - A "recent times" deque continuously reports on recent queries so that increases in query time are visible.
  - Queries are logged along with the time taken, for tracking performance over the long term.
  - Documented in [documentation/Performance.md](../documentation/Performance.md).

## Improvements
- Renamed `reverse_lookup()` to `curie_lookup()` and `lookup_names_(get|post)` to `synonyms_(get|post)` for
  clarity ([PR #253](https://github.com/NCATSTranslator/NameResolution/pull/253)).
- Fixed a typo in data-loading/README.md ([PR #253](https://github.com/NCATSTranslator/NameResolution/pull/253)).
